# spec-generator (scaffold)

A Claude skill, in design stage: turns PRDs/ERDs into researched, cross-validated, versioned and
live-validated API specs, published as an Astro + React Bits site.

- `SKILL.md`: skill description, stage definitions (0–7), tooling
- `PLAN.md`: build plan, file status (✅ done / 🟡 stub or outline), milestones M1–M5

**Not usable as an installed skill yet.** Most scripts are stubs and the references are outlines.
Start with milestone M1 (`references/schemas.md`).
