# Source research — STUB (milestone M1)

Outline:
1. Discovery order: published OpenAPI/AsyncAPI (/openapi.json, /swagger.json, docs "download spec" links,
   provider GitHub repos, APIs.guru) → official reference docs → official SDK source → changelog/status pages
   → Postman public collections → community (tertiary, always flagged).
2. Source modes: docs / sites / web / mixed, and what "outside provided set" flagging means.
3. Recording sources: id, url, title, kind, trust, retrievedAt; quote-level precision where a claim is subtle.
4. Quota hunting: "rate limits", "limits", "quotas", "usage", pricing pages, response headers, SDK retry/backoff code.
5. Per-operation capture list: params, schemas, pagination, errors, idempotency, version headers, deprecation/sunset, scopes.
6. Sample data: doc examples and spec examples now; live captures in Stage 6.
7. Writing a good gap: question, whySought, whereLooked (real URLs/queries), impact, suggestedResolution.
8. Staleness: compare doc dates against the changelog; flag conflicting sources as findings rather than picking one silently.
