# Site — STUB (milestone M3)

Astro (static) + React islands + React Bits components (SpotlightCard, Counter, StarBorder, SplitFlapText in
assets/site-template/src/components/rb, license: MIT + Commons Clause).

Pages:
- `/` overview: counters (specs, operations, verified, gaps), requirement → spec map, relations, spec cards with gate status.
- `/specs/[id]` and `/specs/[id]/v/[n]`: auth & authz (methods, chosen, scopes with requiredBy, roles, account types),
  endpoint explorer (Swagger-like: list grouped by tag, provenance badge, scopes, params, schemas, recorded validation
  response, try-it with token held in memory only, optional proxy, curl snippet), quotas (documented vs observed),
  findings, gaps, requirements coverage, setup (SETUP.md), sources.
- `/specs/[id]/timeline`: version timeline (semver, bump badge, message, counts, validation ratio).
- `/specs/[id]/compare`: pick two versions → structural diff + unified line diff per file.
- `/compare/[group]`: candidate comparison matrix (sticky first column, per-cell source popovers, recommendation, selected badge).
- `/cross`: cross-API hand-off checks (from → to, expected constraint, static result, live result).
- Corroboration badges everywhere a claim appears: single · corroborated (n) · conflicting → link to the conflict finding.

Data: everything comes from `src/data/project.json`, generated by `specgen.py site`. Pages never compute provenance.
Theming: light/dark tokens; dense, technical typography; monospace for paths and payloads.
